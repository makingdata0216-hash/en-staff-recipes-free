# en STAFF RECIPE BOOK

Shisha Cafe&Bar en のスタッフ用静的レシピサイトです。画像・検索・お気に入りの閲覧で生成AI APIや従量課金APIは呼びません。

## ファイル構成
- `index.html` — 画面のHTML（軽量）
- `styles.css` — デザイン
- `app.js` — 検索・お気に入り・レシピ表示・CSV管理などの画面処理
- `data.js` — 64レシピと6マニュアルのテキスト・画像パス
- `assets/*.webp` — 料理・マニュアルの元画像とサムネイル。WebP実ファイルで120点

## 更新ルール
1. 原則として変更用のブランチで作業し、更新前にメニュー数・画像参照・JS構文・表示を検証します。
2. レシピ本文や新しいメニューは `data.js` 内の `window.EN_DATA.recipes` を編集します。接客マニュアルは `manuals` を編集します。
3. 画像は `assets/<商品ID>-image.webp`、サムネイルは `assets/<商品ID>-thumbnail.webp` に保存し、`data.js` で相対パスを参照します。画像なしのレシピは空欄を維持します。
4. 画像内に文字がある場合はテキストレシピとの整合も確認します。異なる料理のレシピ画像を1枚にまとめません。
5. `index.html` に画像をbase64で埋め込まないでください。外部画像URL、AI API、従量課金API、トラッキングは追加しません。
6. サイト上のCSV/ローカル編集とお気に入りはブラウザ内にのみ保存され、GitHubへ自動反映されません。新データの公開は別途GitHubの変更が必要です。

> GitHub Pagesは原則としてURLを知る人なら閲覧できます。robotsのnoindex設定はアクセス制限ではありません。従業員の個人情報や秘密情報は掲載しないでください。
